# Thirukural-Alagidudhal-Python
This project is a Python-based automation tool designed to perform Alagidudhal (metric analysis) on all 1330 couplets of the Thirukkural. Built on the principles of Tamil Venpa Grammar, the tool algorithmically breaks down each Kural into its constituent Seers (feet), identifies the Asai, and generates the corresponding Vaipadu.

Key Features:
1.Dynamic Analysis: Accepts any user-input Kural to generate its prosody map in real-time.
2.Grammar-Engine: Implements rules for Kuril, Nedil, and Ottru to accurately classify Asai.
3.Venpa Validation: Serves as a foundation for validating the strict structural rules of the Kural Venba meter.

Thirukural Input :  கற்றதனால் ஆய பயனென்கொல் வாலறிவன் நற்றாள் தொழாஅர் எனின்
